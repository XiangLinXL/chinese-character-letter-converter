# Chinese Character Letter Encoding Converter (汉字字母编码转换器)

一个纯前端（HTML/JS）实现的趣味汉字编码与解密工具，支持中英双语界面与实时转换。

## 🌟 功能特点
- **30 进制编码池**：使用 26 个英文字母（A-Z）加上数字（4,5,7,9），共计 30 个字符。
- **海量容量**：三位字符组合可达 27,000 种，足以覆盖 21,003 个常用及生僻汉字。
- **双向实时转换**：输入汉字实时生成编码；输入编码实时还原汉字。
- **智能标点保留**：句子中的标点符号原样保留，阅读更直观。
- **极简交互**：支持一键复制、原生长按选择复制，并带有防打扰的 Toast 提示。
- **竖屏优化**：使用多行输入框与强制折行，完美适配手机竖屏。

## 📥 如何获取字典文件（非常重要！）
本转换器本身只包含算法，**必须配合字典文件才能运行**。
1. 在本仓库文件列表中，点击 **`chinese-character-list.txt`**。
2. 点击右上角 **"Download raw file"** 下载保存。
3. 打开网页后，在“加载字典”处选择该文件即可使用。

## 📖 编码规则说明
以 GBK 汉字表的汉字顺序为基础，按 30 进制依次分配（如第 1 个字“啊”对应 `AAA`）。连续汉字的编码之间使用横杠 `-` 分隔。
